# Road Accident Analysis

## Project Overview
Analysis of road accident data to understand accident trends and causes.

## Objective
To identify accident-prone areas and contributing factors.

## Dataset
Road accident dataset with location, time, and severity details.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Steps
- Data cleaning
- EDA
- Visualization
- Trend analysis

## Key Insights
- Certain time periods have higher accidents
- Specific locations are high-risk zones
